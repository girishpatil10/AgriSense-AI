# AgriSense-AI 🌱

AI-powered smart agriculture platform that brings multiple agricultural AI capabilities into one application.

## 📌 Features

- 🌾 Crop Recommendation
- 🧪 Soil NPK Analysis
- 🧴 Fertilizer Recommendation
- 🍃 Plant Disease Detection
- 📈 Crop Yield Prediction

## 🛠️ Tech Stack

### Frontend
- React.js
- TypeScript

### Backend
- Python
- FastAPI
- REST APIs

### AI / Machine Learning
- Machine Learning
- Deep Learning
- PyTorch
- XGBoost
- ResNet-50
- Hugging Face Inference APIs

### Database & Infrastructure
- PostgreSQL
- Redis
- Docker

## 🏗️ Architecture

The application consists of:

1. React/TypeScript frontend
2. FastAPI backend
3. AI inference layer
4. PostgreSQL database
5. Redis caching layer

## 📊 Results

The project includes multiple AI/ML modules for agricultural decision support, including crop recommendation, soil analysis, fertilizer recommendation, disease detection, and yield prediction.
